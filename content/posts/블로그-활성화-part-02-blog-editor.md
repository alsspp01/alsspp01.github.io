이전 포스트에서 블로그의 전반적인 아키텍처와 기능을 다루었다면, 이번에는 로컬에서 마크다운 파일을 직접 생성하고 수동으로 배포하는 번거로움을 해결하기 위해 개발한 전용 관리 도구인 **'Blog Editor'**를 자세히 소개한다.

### 1. 개발 배경

Hugo 기반의 정적 사이트(SSG)는 우수한 보안성과 빠른 속도를 자랑하지만, 콘텐츠를 관리할 때 다음과 같은 번거로운 단계를 거쳐야 한다.

1. 로컬 환경에서 마크다운 파일 생성 및 프론트매터(Front Matter) 메타데이터 수동 작성
2. 로컬 서버(`hugo server`)를 구동하여 렌더링 결과 확인
3. 변경 사항을 Git 명령어(`git add`, `commit`, `push`)를 통해 원격 저장소에 수동 반영

이러한 로컬 종속성과 번거로운 작성 흐름을 개선하고, 브라우저 환경에서 쉽고 빠르게 글을 쓰고 배포할 수 있도록 셀프 호스팅 기반의 웹 도구인 **Blog Editor**를 직접 구축했다.

### 2. Blog Editor의 주요 핵심 기능

Blog Editor는 마크다운 작성부터 Git 버전 관리, 최종 배포까지 블로그 운영 전반을 웹 UI 상에서 원스톱으로 관리할 수 있는 기능을 제공한다.

#### ① 실시간 미리보기 (Live Preview)
*   **위지윅 스타일의 편의성:** 텍스트 에디터 옆에 실시간 마크다운 렌더링 화면을 배치하여, 작성 중인 문서의 스타일과 구조를 즉각적으로 확인할 수 있다.
*   **메타데이터 관리 자동화:** 제목, 작성일, 카테고리, 태그 등의 필수 프론트매터 서식을 에디터 상단의 입력 폼을 통해 직관적으로 기입하고 수정할 수 있도록 설계했다.

#### ② 원클릭 배포 및 버전 관리 (Git Integration & Diff View)
*   **코드 변경 사항 비교(Diff View):** 커밋하기 전에 이전 상태와 새로 수정된 사항을 비교해 볼 수 있는 Diff 뷰를 제공하여 의도치 않은 수정을 방지한다.
*   **터미널 없는 배포 파이프라인:** 작성 완료 후 에디터 내 배포 버튼 클릭 한 번으로 `Git Push`를 실행한다. 이는 사전에 연동된 GitHub Actions 배포 파이프라인을 실시간으로 트리거하여 사이트 빌드 및 최종 배포까지 자동화한다.

#### ③ AI 글쓰기 지원 (Project DIA 연동)
*   **초안 및 가이드라인 자동 생성:** 현재 추진 중인 Project DIA의 핵심 모듈을 탑재하여 작성 보조 기능을 고도화했다. 간단한 핵심 키워드나 주제만 입력하면 AI가 블로그 형식에 적합한 초안을 설계해 준다.
*   **문장 정교화 및 문맥 교정:** 작성된 초안의 자연스러운 연결 흐름을 검토하고, 맞춤법 검사 및 전문적인 어조 조정을 통해 포스팅 완성도를 대폭 향상한다.

### 3. 기대 효과 및 마무리

Blog Editor를 구축한 덕분에 로컬 작업 환경이 아닌 기기에서도 즉각적으로 블로그 글을 업데이트할 수 있는 편의성을 마련했다. 특히 AI 작성 지원 모듈의 결합으로 콘텐츠 기획 및 포스팅 초안 작성 시간을 혁신적으로 단축하는 성과를 거두었다. 향후에는 이미지 업로드 시 자동 최적화 및 메타데이터 자동 생성 기능을 점진적으로 추가하여 더욱 고도화할 예정이다.
