### 0. Make New post or page
#### 💥 Problem
새 문서를 만들었으나 반영이 안 될 때
  
#### 💡 Solution
1. git clone -> local로 파일 가져오기
2. cmd 켜기
3. 해당 local 경로에서 `hugo server` 또는 `hugo`
4. commit & push

> ⛔ Hugo가 안 깔려 있을 경우  
> 1. powershell 관리자 권한으로 열어 chocolatey 깔기  
> 2. `choco install hugo-extended`

### 1. Permission Error
#### 💥 Problem
```
Error: Error copying static files: open 
C:\path\to\myblog\public\static\the_image.png: Access is denied.
```
#### 💡 Solution
경로에 한글이 있을 가능성이 있음.  
경로에 "문서" 등 한글이 있을 경우 static 파일을 읽어들이지 못함 + 권한오류 발생  

---

### 2. Updating the Blog Theme
#### 💥 Problem
블로그 테마 업데이트 및 Submodule 업데이트

#### 💡 Solution
`git submodule update --remote`

---

### 3. MS Word to markdown file
#### 💥 Problem
*.docx 파일을 *.md 파일로 전환하기

#### 💡 Solution
Pandoc 설치 후 변환

[`pandoc 설치`](https://pandoc.org/installing.html)  
  
Chocolatey로 설치  
` choco install pandoc `  
` choco install rsvg-convert python miktex `  

```
pandoc -f docx Source.docx -t markdown -o Output.md --extract-media=./Filename
```

이렇게 하면 Source.docx 파일이 있는 자리에 마크다운 파일 하나와 이미지들이 들어 있는 Filename/media 파일이 생성된다.

---

### 4. 이미지 경로 설정
#### 💥 Problem
이미지 파일은 static/image 폴더에 넣습니다.
경로를 자주 틀려서 까먹지 않게 기록

#### 💡 Solution
``` ![description](/image/foldername/image.png) ```
/image 앞에 . 안 붙는 게 중요함.

### 0. Creating a New Post or Page

#### 💥 Problem

A newly created document does not appear on the site.

#### 💡 Solution

1. Run `git clone` to copy the files to the local machine.
2. Open Command Prompt.
3. Run `hugo server` or `hugo` from the local project directory.
4. Commit and push the changes.

> ⛔ If Hugo is not installed  
> 1. Open PowerShell as an administrator and install Chocolatey.  
> 2. Run `choco install hugo-extended`.

---

### 1. Permission Error

#### 💥 Problem

```
Error: Error copying static files: open 
C:\path\to\myblog\public\static\the_image.png: Access is denied.
```

#### 💡 Solution

Check whether the path contains Korean characters. A folder with a Korean name, such as `문서`, may prevent Hugo from reading static files and result in a permission error.

---

### 2. Updating the Blog Theme

#### 💥 Problem

Update the blog theme and its Git submodule.

#### 💡 Solution

`git submodule update --remote`

---

### 3. Converting an MS Word Document to Markdown

#### 💥 Problem

Convert a `.docx` file to a `.md` file.

#### 💡 Solution

Install Pandoc and run the conversion.

[`Install Pandoc`](https://pandoc.org/installing.html)  
  
Install with Chocolatey  
` choco install pandoc `  
` choco install rsvg-convert python miktex `  

```
pandoc -f docx Source.docx -t markdown -o Output.md --extract-media=./Filename
```

This creates a Markdown file next to `Source.docx` and a `Filename/media` directory containing the extracted images.

---

### 4. Setting an Image Path

#### 💥 Problem

The image file is stored under `static/image`. I recorded the path syntax because I often forgot it.

#### 💡 Solution

```markdown
![description](/image/foldername/image.png)
```

The important point is not to add `.` before `/image`.
