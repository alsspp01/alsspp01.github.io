## Link

#### [Mid-Term-Project](/mid-term-project/)

This was the midterm assignment for DKU's Open-Source Software course in the first semester of 2024.

---

### 1. Task: Build a Personal Website

- Create a website introducing yourself; templates were allowed.
- Include at least two images and one video.

### 2. GitHub Requirements

- Create and work in a repository named `Mid-Term-Project`.
- Make at least 15 commits.
- Host the site with GitHub Pages or an external server.

### 3. Submission

- Submit an accessible URL by April 29 and keep it online through the end of June.
