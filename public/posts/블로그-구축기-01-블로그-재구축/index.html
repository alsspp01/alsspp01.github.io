블로그 구축기 01 - 블로그 재구축

Project GIA(Give It to AI) #2

July 22, 2026

개요

개인 블로그(alsspp01.github.io)를 정적 사이트 생성기(Static Site Generator)인 Hugo로 재구축하고, GitHub Pages 및 GitHub Actions를 활용한 자동 배포 환경을 파이프라인으로 구성했습니다. 이번 글에서는 블로그 사이트 자체의 보수 내역과 아키텍처를 개발 문서 형태로 정리합니다.

시스템 아키텍처

[ 블로그 구성 아키텍처 다이어그램 ]

블로그 시스템의 핵심 구성 요소는 다음과 같습니다.

  • SSG Engine: Hugo
  • Theme: Gokarna (Custom Fork)
  • Hosting: GitHub Pages
  • CI/CD Pipeline: GitHub Actions
  • Dynamic Backend Service: SQLite + Tailscale Funnel (좋아요/공유 연동)

Hugo 및 테마 커스터마이징

gokarna 테마를 커스텀 포크하여 사용 중이며, 개인 블로그의 목적에 맞게 파셜(Partial) 템플릿과 스타일을 보수했습니다.

# config.toml 설정 일부
baseURL = "https://alsspp01.github.io/"
languageCode = "ko-kr"
title = "alsspp01's Blog"
theme = "gokarna"

[params]
  description = "Personal Blog & Project Showcase"
  showReadTime = true

[ 수정된 Gokarna 테마 메인 화면 스크린샷 ]

주요 보수 사항

  1. Projects 페이지 및 Period 정렬 구조: 프로젝트 카드에 시작/종료 연월(period) 메타데이터를 추가하고, 이에 따라 자동 정렬 및 노출 여부가 결정되도록 템플릿 수정
  2. 검색 및 태그 필터링: 태그 검색 시 AND/OR 논리 연산을 지원하는 필터링 기능 구현
  3. 인터랙션 요소 추가: 포스트 하단에 좋아요(Like) 및 공유(Share) 버튼 UI 적용

CI/CD 자동 배포 파이프라인

main 브랜치에 코드가 푸시되면 GitHub Actions가 트리거되어 정적 파일 빌드 및 gh-pages 배포를 수행합니다.

name: Deploy Hugo Site

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          submodules: true
          fetch-depth: 0

      - name: Setup Hugo
        uses: peaceiris/actions-hugo@v2
        with:
          hugo-version: 'latest'
          extended: true

      - name: Build
        run: hugo --minify

      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./public

[ GitHub Actions 실행 성공 화면 ]

동적 backend 연동 (좋아요 / 공유)

정적 페이지의 한계를 극복하기 위해 별도의 경량 backend 서비스를 연동했습니다.

  • Database: SQLite
  • Network: Tailscale Funnel을 통해 로컬 네트워크 내 백엔드를 외부 엔드포인트로 안전하게 노출
